# T015 — Fly-Brain + Ollama Co-Processor PoC

## Context

User spec: a biological neural co-processor in Python where fly-brain connectome
circuits act as the dynamic internal engine (temperament, focus, habituation) for a
chatbot backed by a local Ollama model. Target: Steam Deck. No physics, no graphics —
pure neuronal tensor propagation. Compute must run on CPU, isolated, non-blocking,
< 1.5 GB RAM; neuronal step time ≤ 50 ms per conversation turn.

Verified on Deck: Ollama live at `http://127.0.0.1:11434` with **llama3.1:8b**
(no separate `ollama` CLI in PATH; server reachable both locally and via LAN).

## Architecture (spec-mandated)

- **Module A — `fly_coprocessor.py`**: E-PG ring attractor (circular network,
  lateral inhibition, single bump, measures topic rotation/drift); mushroom body
  (sparse Kenyon cells → MBONs, DAN reward/punishment, topic affinity/aversion);
  neuromodulatory pool (octopamine fire-rate integrator with exponential decay =
  habituation).
- **Module B — `semantic_encoder.py`**: topic/keyword hash → angle 0..360° drives
  E-PG bump; injects current into MB sensory cells; identical/too-fast messages
  reduce injection amplitude (pre-synaptic habituation).
- **Module C — `neuro_to_ollama.py`**: maps connectome state to Ollama params
  (low Oct → temp 0.2 / num_predict 80; high Oct → temp 0.7 / num_predict 250;
  E-PG jump >120°/turn → prepend "[Nota interna: O utilizador mudou subitamente de
  tema]" to system message; aversive MBON balance → moderation/caution constraint).
- **Module D — `chat_cli.py`**: CLI loop, `++`/`--` feedback (reward/punishment
  DANs), telemetry line before each response:
  `[Bússola: 42° | Alerta (Oct): 0.78 | Afinidade: +0.35 | Temp: 0.65]`.
- **`test_coprocessor.py`**: 5 synthetic dialogue turns validating (1) E-PG gradual
  vs abrupt topic change, (2) octopamine depression under rapid repetitive loops,
  (3) `++`/`--` synaptic weight updates.

## Proof (2026-09-20)

- `make test`: **105 passed, 1 skipped** (13 new co-processor cases).
- `make lint`: **All checks passed**.
- `make check`: docs/code/test/lint/safety green (coverage 43% pre-existing, non-gating).
- Neuronal step timing: **0.229 ms/turn** (1000 steps, incl. semantic encoding);
  spec budget 50 ms.
- Offline mock CLI: telemetry lines correct, `++`/`--` recorded.
- Live Ollama on Deck (`http://steamdeck:11434`, llama3.1:8b):
  prompt `fala-me de drones` → telemetry `[Bússola: 99° | Alerta (Oct): 0.49 | Afinidade: +0.16 | Temp: 0.51]`;
  prompt `física quântica` (abrupt switch) → `[Bússola: 323° | Alerta (Oct): 0.73 | Afinidade: -0.00 | Temp: 0.70]`.
  The E-PG bump rotated from 99° to 323° (≥120° jump), octopamine rose (0.49→0.73),
  temperature moved in lockstep (0.51→0.70) — the connectome visibly shaped the reply.
- Ollama raw latency on Deck APU: ~4 tok/s for llama3.1:8b; full reply ~45-170 s
  (cold model load dominates). Co-processor step itself is microseconds.

## Hazards / notes

- affinity normalization: affinity clamped to [-1, 1].
- `persistent replies`: Deck APU is slow for 8b; `--base-url` warmup call sets
  `keep_alive=30m` to avoid mid-demo cold-load stalls.
- Leftover deck probe files were already removed (T014); sim scratch bridge
  `fly_ollama_bridge.py` kept for reference only.
